## Publishing a clean export (recommended for privacy)

The supplied Git history may contain unredacted personal notes. Extract the
project ZIP to a **new directory**, replace `<name>` in LICENSE and review all
files before creating a fresh public history. Do not run git init over the
existing Arena checkout to try to remove history.

```bash
# In a newly extracted, reviewed directory without .git:
git init
# Pick the branch name for YOUR clean export, not the Arena working checkout:
git add .
git commit -m "Release Vivobook Optimize v16.1 (audit fixes A-01..A-08)"
git tag -a v16.1.0 -m "Vivobook Optimize v16.1.0"
# Replace OWNER before running; no credentials belong in the URL:
git remote add origin https://github.com/OWNER/vivobook-optimize.git
git push -u origin HEAD
git push origin v16.1.0
```

In the **existing Arena checkout**, the session is fixed to
`arena/2af007f1-vivobook-optimize`. Review the privacy implications of existing
history before pushing. If you deliberately keep that history, suggested commands
(not executed here) are:

