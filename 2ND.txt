### C-04 — Guard sleep hooks, refresh them in place, show installed-vs-enabled (P1)

**Rationale:** F-04.

**Files affected:** the four hook heredocs (battery 3959, thermal 4155, EPP 4316, kbd 5256), one new default-run step, and the "Persistent service" lines in `show_status_dashboard`.

**Exact modification:**

```bash
# v16 (C-04): single source for the four resume hooks. Restart only if the unit is
# still enabled; a disabled unit is the operator's explicit "not at boot/resume".
sleep_hook_body() {
  local unit="$1"
  cat <<HOOK
#!/usr/bin/env bash
# Managed by vivobook_optimize.sh v16
if [[ "\${1:-}" == post ]]; then
  if systemctl is-enabled --quiet ${unit} 2>/dev/null; then
    systemctl restart ${unit} >/dev/null 2>&1 || true
  fi
fi
HOOK
}
```

Each existing hook heredoc becomes `atomic_write <hook> 0755 <<< "$(sleep_hook_body <unit>)"`. A here-string is used per I-24, never a pipe, so `TMP_REGISTRY` survives.

New step, placed after step 15c and before step 16:

```bash
echo "== 15d. Refresh existing managed sleep hooks (no enable/start) =="
for pair in vivobook-battery:battery-charge-threshold.service \
            vivobook-thermal-profile:asus-thermal-profile.service \
            vivobook-intel-epp:intel-epp-profile.service \
            vivobook-kbd-timeout:vivobook-kbd-timeout.service; do
  hook="/usr/lib/systemd/system-sleep/${pair%%:*}"
  is_managed_file "$hook" || continue            # never create, never touch unmanaged
  want="$(sleep_hook_body "${pair#*:}")"
  if [[ "$(cat "$hook" 2>/dev/null)" == "$want" ]]; then

    chmod 0755 "$hook"

done
```
